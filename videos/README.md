# videos/ 目录说明

博客第四章 4.1 节「三个阶段的成长」预留了 3 个视频位置。
请把你的三个训练回放视频放到本目录，并按以下命名（与博客中的引用一一对应）：

| 视频内容              | 需要的文件名                          | 博客中的位置                          |
| ----------------- | ------------------------------- | ------------------------------- |
| 第 0 次训练的回放（出生即摔）   | `microduck_step0.mp4`           | 4.1 节第 1 个 `<video>` 标签         |
| 第 2499 次训练的回放（能走）  | `microduck_step2499.mp4`        | 4.1 节第 2 个 `<video>` 标签         |
| 第 4999 次训练的回放（稳健）  | `microduck_step4999.mp4`        | 4.1 节第 3 个 `<video>` 标签         |

放入文件后无需改动博客——三个 `<video>` 标签已按这些文件名写好。

提示：如果文件名不同，也可以直接改 `microduck_技术博客1.1.md` 里对应 `<source src="...">` 的路径。
